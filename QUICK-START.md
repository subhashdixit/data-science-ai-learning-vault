# 🚀 Quick Start Guide

Get started with your colorful learning notes in 5 minutes!

---

## Step 1: Install Obsidian (2 minutes)

1. Go to: https://obsidian.md/
2. Download for Mac/Windows/Linux (FREE!)
3. Install it

---

## Step 2: Open This Folder in Obsidian (1 minute)

1. Open Obsidian
2. Click **"Open folder as vault"**
3. Select: `/Users/subhash_dixit/Documents/codex/connected-ai-learning/learning-notes`
4. Click **"Open"**

---

## Step 3: Enable Color Snippets (1 minute)

1. In Obsidian: **Settings** (gear icon) → **Appearance**
2. Scroll to **CSS snippets**
3. Click refresh icon (⟳)
4. Enable **"handwritten-colors"** toggle

**You should now see colorful callouts!** 🎨

---

## Step 4: Test the Colors! (1 minute)

Create a new note and try this:

```markdown

> [!blue] 💙 Blue Box - Concepts
> This is a concept explanation

> [!green] 💚 Green Box - Examples
> This is a working example

> [!red] ⚠️ Red Box - Warnings
> This is a critical warning

> [!yellow] 💡 Yellow Box - Important
> This is an important tip

> [!purple] 🔮 Purple Box - Advanced
> This is advanced content

Regular ==blue highlight==<!--blue-->
